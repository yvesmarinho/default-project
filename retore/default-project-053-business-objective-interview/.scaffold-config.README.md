# Scaffold Configuration

Este arquivo permite customizar os valores padrão do `scaffold.py` sem modificar o código.

## 📋 Configuração

### `defaults`
Valores padrão usados quando criar novos projetos.

- **`target_dir`**: Diretório onde novos projetos serão criados
  - Padrão: `~/Documentos/DevOps/Projects`
  - Suporta `~` para home directory
  - Exemplo: `"~/work/projects"` ou `"/opt/projects"`

- **`shared_dir`**: Diretório de arquivos compartilhados (`.copilot-rules.md`, etc.)
  - Padrão: `~/Documentos/DevOps/.copilot-shared`
  - Usado para symlinks de configuração
  - Exemplo: `"~/.copilot-shared"` ou `"/usr/local/share/copilot"`

- **`domain`**: Domínio padrão para novos projetos
  - Opções: `"programming"`, `"infrastructure"`, `"analysis"`
  - Padrão: `"programming"`

- **`language`**: Linguagem padrão para novos projetos
  - Opções: `"python"`, `"typescript"`, `"go"`, `"other"`
  - Padrão: `"python"`

- **`github_org`**: Organização GitHub padrão
  - Padrão: `"Vya-Digital"`
  - Usado ao construir URLs de repositório

### `paths`
Caminhos relativos dentro do template.

- **`profile_descriptors`**: Pasta de perfis YAML
- **`templates`**: Pasta de templates de código

### `features`
Funcionalidades opcionais do scaffold.

- **`auto_git_init`**: Inicializar repositório Git automaticamente
- **`create_venv`**: Criar ambiente virtual Python
- **`setup_symlinks`**: Criar symlinks `.copilot-*` automaticamente
- **`validate_on_create`**: Validar estrutura após criação

### `prompts`
Configuração de UI/prompts.

- **`show_emoji`**: Mostrar emojis nos prompts
- **`verbose`**: Modo verbose (mais detalhes)
- **`color_output`**: Saída colorida

## 📝 Exemplo de Uso

**Cenário**: Você trabalha em `/mnt/projects` e quer mudar o padrão:

```json
{
  "defaults": {
    "target_dir": "/mnt/projects",
    "shared_dir": "~/.config/copilot-shared",
    "domain": "infrastructure",
    "language": "typescript"
  }
}
```

Agora quando executar:
```bash
uv run scripts/scaffold.py new
```

O prompt já virá com `/mnt/projects` como padrão ao invés de `~/Documentos/DevOps/Projects`.

## ⚙️ Como Funciona

1. `scripts/lib/config.py` lê este arquivo JSON
2. Se arquivo não existir ou houver erro, usa valores hardcoded
3. Valores do JSON **sobrescrevem** os defaults
4. Usuário pode sobrescrever via CLI: `--target-dir /outro/caminho`

## 🔒 Segurança

- Arquivo versionado no template (sem dados sensíveis)
- Cada projeto pode ter seu próprio `.scaffold-config.json`
- Não armazene tokens/credenciais aqui (use `.secrets/.env`)
