# Skill: grill-with-docs
**Versão:** 1.0.0

## Objetivo
Interrogar a demanda até remover ambiguidades críticas com base em documentação existente.

## Entradas
- Pedido bruto
- `CONTEXT.md`
- ADRs e docs

## Procedimento
1. Listar ambiguidades
2. Cruzar com documentação
3. Propor hipóteses explícitas
4. Converter em perguntas objetivas
5. Consolidar entendimento final

## Saída
- Resumo validado do problema
- Lista de dúvidas resolvidas/não resolvidas
- Premissas assumidas
