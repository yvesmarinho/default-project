# Skill: tdd
**Versão:** 1.0.0

## Objetivo
Guiar implementação por testes com ciclos curtos.

## Ciclo
1. Red: escrever teste que falha
2. Green: implementar mínimo para passar
3. Refactor: melhorar design sem quebrar testes

## Regras
- Não avançar sem falha reproduzível
- Não refatorar sem rede de testes
- Commit por ciclo funcional
