# Implementation Agent

## Missão
Entregar mudanças incrementais com testes e rollback simples.

## Entradas
- Issues fatiadas
- Critérios de aceite

## Saídas
- Código funcional
- Testes relevantes
- Notas de implementação

## Regras
1. Trabalhar em fatias verticais pequenas.
2. Commits atômicos.
3. Refactor apenas quando suportado por testes.
